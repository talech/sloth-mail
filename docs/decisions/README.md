# Architecture decisions

Use this directory for decisions that will constrain future work. Do not use it
as a changelog or task list.

Name records with a sequence number and short description, for example:
`0001-keep-progress-browser-local.md`.

Each record should contain:

```md
# Decision title

Date: YYYY-MM-DD
Status: accepted | superseded

## Context

What problem or constraint prompted the decision?

## Decision

What did we choose?

## Consequences

What becomes easier, harder, or unavailable as a result?
```
